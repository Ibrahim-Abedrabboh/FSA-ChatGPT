What “using you as agents” means

A separately deployed reasoning capability supplied with the project’s files, styling skill, tools and authoritative memory. It does not reuse this desktop chat as a backend or assume that my current connectors are website credentials.

Recommended pattern: a manager invokes specialist tools; an independent critic assesses the actual images. A managed Agents API is an alternative to an application-controlled SDK runtime. Account access and integration still require execution evidence.

THE BUSINESS STANDARD

Cost per accepted complete package.

Include failed calls, repairs, review, compute and human time. More agents are useful only if they improve the total result.

A · Controlled workflow

Cost comes from extraction, planning, catalogue retrieval, generation, critique and repairs. Narrow calls and stable routes may reduce overhead; that saving must be measured.

B · Adaptive agents

Add manager turns, context, tool calls and optional sandbox time. Better diagnosis or composition could avoid expensive rework; extra turns can also make it worse.

Reserve before work

Production budgets must cover every reasoning, retrieval, image and review call, including maximum completion costs. The reference lab implements rendering reservations and adaptive-action charges only.

Time has two measures

Track human active minutes separately from total elapsed time. Publish median and slow-case latency, queue wait and failure recovery for complete packages.

Acceptance remains the denominator

Cheap rejected images are not a business win. With zero accepted packages, cost per accepted package is undefined, not zero.

AUDIT · LOCAL PROOF · PRODUCTION GATES

What exists, and what earns release.

Build gates

  1. Contract foundation. Shared intake, immutable evidence, category packages and ownership.
  2. Provider proof. Actual server-readable generation and critic receipts; real files and usage.
  3. A vertical slice. Entire package advances with browser closed and survives a worker restart.
  4. B shadow execution. Deployed manager makes adaptive decisions under the same supervisor.
  5. Paired benchmark. Hard cases and unseen SKUs; calibrated quality, cost and latency criteria.
  6. Client cutover. Connect validated families through a feature flag with rollback to review-only.
Fidelity target: ≥95% needs a calibrated measurement method and approved anchors. Zero critical violations is a release gate. A self-reported percentage or successful unit test is not a fidelity measurement.
