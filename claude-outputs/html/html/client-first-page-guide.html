Start with Projects or Manual

Projects

Start from a product or collection, an existing room, a new styled space, or saved work. These four starting options belong under Projects. The default automated workflow handles the process; input, category and the required result steer it.

Manual

Choose New Project, Edit or Single item, followed by the relevant option beneath it. Continue through The Item, Scope, Preferences and Suggestions. These sections organise your choices; the solution still handles the workflow. Optional controls can be left at their defaults.

Product or collection

Start with one product, several products, or a complete set. Upload vendor images, clean product images, lifestyle photographs, multiple views, or select catalogue references. Several photographs may describe one item; they are not automatically several products.

Existing room

Supply the room and the products to place, replace or restyle. The room reference defines the space to retain; product references define the items.

New styled space

Start a new room composition from products and a room description. The space is created around the required pieces, with coordinated supporting products.

Saved project

Continue saved work, refine selected elements or request variations while retaining the original references and accepted direction.

1 · The Job

New Project → Batch

Prepare several items together. Keep each item or set separate, group its different reference views, and keep category-specific output packages. A batch is not a single collage or a room made from unrelated products.

New Project → One by one (same department)

Work on one item or set at a time, with the department carried forward to the next item. Each item can have multiple input references and several required output images.

Edit → Choose from saving

Use a saved project as the starting point. Carry its references and accepted direction forward; describe only the requested change.

Edit → New item

Bring an image or item into an editing task. It may be a product image, a composition or a room. Supply the relevant reference and the change you need. Choosing this option does not force a room-furnishing scenario.

Single item → Hero

Make the supplied item the main subject. A small accessory can be the hero: select appropriate Midas furniture and supporting objects around it, with a readable product view and detail image.

Single item → Secondary

Use the item inside a composition supporting the main furniture or room. Keep it recognisable and correctly placed, without forcing it to become the largest object in the image.

What are you starting with?

Under Projects, choose product/collection, existing room, new styled space or saved project. Manual begins with its own Job choices and accepts the relevant reference types without asking this second starting question.

2 · The Item

Department → Category → Sub-category

Use the predefined product hierarchy to identify the department, category and sub-category. It covers furniture and other home categories, including accessories, textiles and lighting. The selected item determines relevant treatment and outputs. Website collections and sections are labelled separately from the main departments.

Automatic from references

Leave an unknown category for the intake process to determine from the supplied image and product information. Recognition and interpretation are part of normal intake for every item, not a special case reserved for difficult products.

Item defines the workflow

The category changes what to preserve, how to place the item, what details need review and which images belong in its package. Input content and item role steer that same workflow.

Product images / other views or pieces

Vendor raw images, clean packshots, products photographed in a room, multi-view sheets, and set components can all be references. Assign roles and describe set relationships. Insets, arrows, crosses and colour swatches are evidence to interpret, not extra physical items.

Room / previous result / inspiration / specification files

Room images define an existing space. Previous results carry forward an accepted composition or look. Inspiration communicates style. Text, PDF or the client’s Excel supplies product facts and instructions. An item can have several reference types at once.

3 · The Scope and the solution

White BK

A clean white-background catalogue result. Preserve product shape, pieces, finish and relevant details. Room paint, flooring, plants, people and room styling are set aside for this output.

Lifestyle

Place the product in a complete, believable styled setting. Coordinate scale, contact shadows, lighting and supporting pieces while keeping the product readable.

Website

Prepare the product’s website image set using the relevant category template. A bed, dining table, textile or accessory needs its own useful views and details; a set is not represented by only one image. The template and requested variations define the package.

New Composition

Create a coordinated arrangement of products in a space. Respect the exact item inventory, relationships, room constraints and any chosen Midas combinations.

Variations

Create related alternatives with controlled changes in lighting, style or camera view. Keep the original product identity and set inventory across the alternatives. Choose which variables change.

Create with this item

Use the selected item as the design anchor. For an accessory, choose furniture that complements it; for a furniture hero, select supporting Midas accessories. Role still determines prominence.

Others

Describe an outcome not covered by the predefined choices. It becomes an explicit brief instruction, not an unlabelled generic generation.

View and delivery

Use the category template by default. When needed, request a wider view or close-up, choose image proportions or resolution, and set the number of variations. These are output variables, not separate workflows.

More than one outcome

Combine relevant deliverables for one product, for example white background + lifestyle + website package. Room controls apply only to the outputs that use a room.

4 · Preferences

Lighting · 3 options

Soft daylight: clear, natural product readability. Golden afternoon: directional warmth and softer mood. Warm evening: a lit interior with controlled contrast. These names are proposed defaults; your PDF specified three options without naming them.

Wall paint · 8 options

White, Ivory, Sand, Greige, Taupe, Sage, Charcoal and Terracotta steer the room palette. They are visual directions, not paint codes or claims about the product colour. The eight names are proposed defaults.

Floor · 4 options

Light oak, Dark walnut, Limestone and Marble steer the surrounding floor finish. The four names are proposed defaults, not vendor material specifications.

Category and scope relevance

Preferences are optional and appear in Manual. White-background-only work does not need a wall or floor. Existing rooms should retain their actual architecture unless the brief requests a change.

5 · Suggestions

Plants

Optional greenery supporting the composition. Keep plant scale, placement and sight lines appropriate; do not cover key product features. Your document calls this “Plantary”.

Human

Optional lifestyle presence for scale or use context. Avoid hiding the product, changing its geometry or making the person the main subject unintentionally.

Mood / Vibes

Automatic, Calm & natural, Warm & inviting, Refined & elegant, or Bold & expressive. These proposed directions shape composition, palette and lighting together; they do not permit changing the product.

Optional continuation · 7–15

7 · Specific items / Combo

Specify particular Midas items or a combination using product selections, links or SKUs. Furniture can lead the composition with supporting accessories, and an accessory can lead with supporting furniture. Selection should respect style, purpose, scale and the supplied product references.

8 · Additional input data

SKU identifies a product. Dimensions guide plausible scale when provided. Colour and fabric/material hold supplier facts or clearly labelled observations. Item count and relationships protect cases such as twelve chairs, five seats or excluding a photographed table.

9 · Include description and meta

Yes adds a product description and useful metadata to the requested package; No requests visuals only. Unsupported material, colour or measurements remain unknown.

10 · Use previous generation (space, look)

Attach or select an earlier result and say whether to retain its room, composition or visual direction. It does not replace the original product reference.

11 · Other pieces images

Add companion pieces and additional views, identifying their roles and relationships. Do not count a reverse view or a detail inset as a new saleable item.

12 · Custom prompting

Add concise instructions such as “keep the original windows” or “show the two chairs without the table”. Instructions refine the shared workflow.

13 · Steering and…

This heading is unfinished in the supplied document. No extra fields or workflow requirements are assigned to it. Existing revision instructions belong under Custom prompting until its meaning is defined.

14 · Fidelity / Styling / Cluttering

Fidelity sets preservation priority, Styling sets scene treatment, and Cluttering sets accessory density. Slider values are steering strength out of 100, not measured fidelity, pass scores or permission to alter the product identity. White-background-only output ignores room styling and accessory density.

15 · Share description first

Request a composition description before generation so the user can adjust direction. This is a review preference, not a promise that a description alone validates the image.

15 · Proceed without

Skip that initial description checkpoint. The intended output review still checks inventory, product identity, placement and composition.

15 · Use semantic grounding

Use product features, context and available references to support the interpretation and proposed composition. Visual recognition remains part of the standard workflow. This option adds explicit grounding to the review requested here.

How the page passes a brief forward

1 · Capture

Collect references, category if known, item role, requested outcomes and only the relevant steering.

2 · Prepare

The intended workflow interprets the references, preserves counts and product facts, and selects appropriate Midas supporting pieces or furniture.

3 · Compose and generate

Produce the category-specific image package, composition or controlled variations requested. Preserve the original item, set relationships and the details that must stay consistent.

4 · Review and deliver

Check the result against the original references and requested scope: identity, item counts, placement, composition, styling and assessed fidelity/integrity. Correct specific problems and deliver the requested package, with unresolved issues made clear.

HOW THE SAME PAGE ADAPTS

How choices combine

Examples of how the same workflow adapts to different items and references.

01

A 12-chair dining set

New Project → One by one → Dining Rooms → Lifestyle + Variations

Keep twelve chairs and the table as one set. Create distinct daylight and evening compositions, with selected Midas dining accessories. Deliver the whole-set view and useful details; do not omit chairs to simplify the shot.

02

A five-seat modular corner

New Project → One by one → Living Rooms → New Composition + Website

Several source images describe three modules forming five seats. Keep their arrangement and upholstery, style the room with coordinated Midas tables and accessories, and request wide and close-up views.

03

Two chairs, excluding the table

Single item → Hero → Dining Chairs → Lifestyle

The source may contain a table or selection marks. Explicitly include only the two chairs. Place them in a relevant setting, with their form visible, plus a detail view.

04

An accessory as the starting point

Single item → Hero → Relevant accessory category → Create with this item

A bowl, jewellery box or bookend becomes the main subject. Select suitable Midas furniture around it. A box may need open and closed views; a bookend should be shown performing its actual function.

05

An accessory supporting a room

Single item → Secondary → Accessories → New Composition

Place the same item on an appropriate supporting surface in a furniture-led composition. Keep it at credible scale, physically supported, and coordinated with the palette.

06

Towels, bedding and textiles

New Project → One by one → Relevant textile category → Website

Read swatches, pattern repeats, alternate views and supplier data as references. Show the product in use and close up. A colour swatch is not another physical item, and exact fibre content needs product data.

07

Restyle an existing room

Edit → New item + room reference → Lifestyle

Supply the room, the new product and a placement instruction. Retain room features requested by the user, replace only the selected pieces, and keep a consistent view for comparison.

08

A mixed vendor batch

New Project → Batch → Product or collection

Each item or set has its own references, category and package. A towel, a lamp and a dining set remain separate jobs within the batch. Multiple angles of one product stay together.

09

Continue an accepted look

Edit → Choose from saving → Previous generation → Variations

Reuse the accepted space and original product references. Vary only the chosen dimensions, such as lighting or camera view, while carrying the preserved details forward.
