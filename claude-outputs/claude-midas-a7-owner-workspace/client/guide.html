Start with Projects or Manual

Projects Applied by A7

Start from a product or collection, an existing room, a new styled space, or saved work. These four starting options belong under Projects. The default automated workflow handles the process; input, category and the required result steer it.

Manual Applied by A7

Choose New Project, Edit or Single item, followed by the relevant option beneath it. Continue through The Item, Scope, Preferences and Suggestions. These sections organise your choices; the solution still handles the workflow. Optional controls can be left at their defaults.

Product or collection Applied by A7

Start with one product, several products, or a complete set. Upload vendor images, clean product images, lifestyle photographs, multiple views, or select catalogue references. Several photographs may describe one item; they are not automatically several products. Add another item only for a different product or set: each item is its own job.

Existing room Applied by A7

Supply the room and the products to place, replace or restyle. The room reference defines the space to retain; product references define the items.

New styled space Applied by A7

Start a new room composition from products and a room description. The space is created around the required pieces, with coordinated supporting products. The room description itself is recorded; A7 does not read it yet.

Saved project Applied by A7

Continue saved work, refine selected elements or request variations while retaining the original references and accepted direction.

1 · The Job

New Project → Batch Applied by A7

Prepare several items together. Keep each item or set separate, group its different reference views, and keep category-specific output packages. A batch is not a single collage or a room made from unrelated products. Each item is saved as its own version in one collection and sent as its own job.

New Project → One by one (same department) Applied by A7

Work on one item or set at a time, with the department carried forward to the next item. Each item can have multiple input references and several required output images.

Edit → Choose from saving Applied by A7

Use a saved project as the starting point. Carry its references and accepted direction forward; describe only the requested change.

Edit → New item Applied by A7

Bring an image or item into an editing task. It may be a product image, a composition or a room. Supply the relevant reference and the change you need. Choosing this option does not force a room-furnishing scenario.

Single item → Hero Applied by A7

Make the supplied item the main subject. A small accessory can be the hero: select appropriate Midas furniture and supporting objects around it, with a readable product view and detail image.

Single item → Secondary Applied by A7

Use the item inside a composition supporting the main furniture or room. Keep it recognisable and correctly placed, without forcing it to become the largest object in the image.

What are you starting with?

Under Projects, choose product/collection, existing room, new styled space or saved project. Manual begins with its own Job choices and accepts the relevant reference types without asking this second starting question.

2 · The Item

Department → Category → Sub-category Applied by A7

Use the predefined product hierarchy to identify the department, category and sub-category. It covers furniture and other home categories, including accessories, textiles and lighting. The selected item determines relevant treatment and outputs. Here it uses the Midas Kuwait English catalogue snapshot of 29 September 2026.

Automatic from references Applied by A7

Leave an unknown category for the intake process to determine from the supplied image and product information. Recognition and interpretation are part of normal intake for every item.

Item defines the workflow

The category changes what to preserve, how to place the item, what details need review and which images belong in its package. Input content and item role steer that same workflow.

Product images / other views or pieces Applied by A7

Vendor raw images, clean packshots, products photographed in a room, multi-view sheets, and set components can all be references. Assign roles and describe set relationships. Insets, arrows, crosses and colour swatches are evidence to interpret, not extra physical items.

Pieces in the photo Applied by A7

How many of each piece the photo shows, for example 2 dining chair. The studio checks its own count against yours before anything is made, so at least one line is required.

Room / previous result / inspiration Applied by A7

Room images define an existing space. Previous results carry forward an accepted composition or look. Inspiration communicates style. An item can have several reference types at once.

Specification files Applied by A7

Text, PDF or the client’s Excel supplies product facts and instructions. A7 reads text, CSV and JSON files; PDF and Excel are stored and listed as not read yet.

Choose from Midas Recorded · not applied by A7 yet

Midas products named as references (SKU or link). To place Midas pieces in the scene, list their SKUs under Specific items, which A7 applies.

3 · The Scope and the solution

White BK Applied by A7

A clean white-background catalogue result. Preserve product shape, pieces, finish and relevant details. Room paint, flooring, plants, people and room styling are set aside for this output.

Lifestyle Applied by A7

Place the product in a complete, believable styled setting. Coordinate scale, contact shadows, lighting and supporting pieces while keeping the product readable.

Website Applied by A7

Prepare the product’s website image set using the relevant category template: the white catalogue image, then hero, wide and close-up views.

New Composition Applied by A7

Create a coordinated arrangement of products in a space. Respect the exact item inventory, relationships, room constraints and any chosen Midas combinations.

Variations Applied by A7

Create related alternatives with controlled changes in lighting, style or camera view. Keep the original product identity and set inventory. Variations start from a saved version A7 already received; the variables to change are sent as an instruction.

Create with this item Applied by A7

Use the selected item as the design anchor. For an accessory, choose furniture that complements it; for a furniture hero, select supporting Midas accessories. Role still determines prominence.

Others Applied by A7

Describe an outcome not covered by the predefined choices. It becomes an explicit brief instruction, sent with at least one other outcome.

View and delivery Applied by A7

Category template by default; a wider view or close-up when needed; nine image proportions; 2K or 4K; five camera views; a three-view or views-by-light series; and the number of variations.

More than one outcome Applied by A7

Combine relevant deliverables for one product, for example white background + lifestyle + website package. Room controls apply only to the outputs that use a room.

4 · Preferences

Lighting · 3 options Applied by A7

Soft daylight: clear, natural product readability. Golden afternoon: directional warmth and softer mood. Warm evening: a lit interior with controlled contrast.

Wall paint · 8 options Applied by A7

White, Ivory, Sand, Greige, Taupe, Sage, Charcoal and Terracotta steer the room palette. They are visual directions, not paint codes or claims about the product colour.

Floor · 4 options Applied by A7

Light oak, Dark walnut, Limestone and Marble steer the surrounding floor finish. They are not vendor material specifications.

Category and scope relevance

Preferences are optional and appear in Manual. White-background-only work does not need a wall or floor. Existing rooms should retain their actual architecture unless the brief requests a change.

5 · Suggestions

Plants Recorded · not applied by A7 yet

Optional greenery supporting the composition, without covering key product features.

Human Applied by A7

Optional lifestyle presence for scale or use context: at most one person, never hiding the product or becoming the main subject.

Mood / Vibes Recorded · not applied by A7 yet

Automatic, Calm & natural, Warm & inviting, Refined & elegant, or Bold & expressive.

Optional continuation · 7–15 (More options)

7 · Specific items / Combo Applied by A7

Specify particular Midas items by SKU. The studio places them when confirmed in stock; product links are recorded but not read yet.

8 · Additional input data Applied by A7

SKU identifies a product. Dimensions guide plausible scale when provided. Colour and fabric/material hold supplier facts. Item count and relationships protect cases such as twelve chairs, five seats or excluding a photographed table.

9 · Include description and meta Always on

Yes adds a product description and useful metadata to the package. No is recorded; the package still carries a draft description.

10 · Use previous generation (space, look) Applied by A7

Continue from a saved version A7 already received and say whether to retain its space, its look or both. It does not replace the original product reference.

11 · Other pieces images Applied by A7

Add companion pieces and additional views with the reference type “Other views / pieces”. A reverse view or a detail inset is not a new saleable item.

12 · Custom prompting Applied by A7

Instructions such as “keep the original windows” or “show the two chairs without the table”, plus details to keep and things to exclude. Instructions, notes and details to keep share 1,200 characters.

13 · Steering and…

This heading is unfinished in the source document. No fields are assigned to it; revision instructions belong under Custom prompting.

14 · Fidelity / Styling / Cluttering Recorded · not applied by A7 yet

Steering strength out of 100, not a measured score. The studio keeps the product exactly as photographed.

15 · Share description first Always on

The studio shares its plan and waits for your plan decision before any image is made; every image then waits for your image decision.

15 · Proceed without Recorded · not applied by A7 yet

Recorded. The plan checkpoint stays on, and the output review always checks inventory, identity, placement and composition.

15 · Use semantic grounding Recorded · not applied by A7 yet

Visual recognition remains part of every job; the explicit grounding option is recorded.

How the page passes a brief forward

1 · Capture

Collect references, category if known, item role, requested outcomes and only the relevant steering.

2 · Prepare

The workflow interprets the references, preserves counts and product facts, and selects appropriate Midas supporting pieces or furniture.

3 · Compose and generate

Produce the category-specific image package, composition or controlled variations requested, preserving the original item and set relationships.

4 · Review and deliver

Check the result against the original references and requested scope, wait for your image decision, and deliver the package with unresolved issues made clear.

How choices combine

Examples of how the same workflow adapts to different items and references.

01

A 12-chair dining set

New Project → One by one → Dining Rooms → Lifestyle + Variations

Keep twelve chairs and the table as one set. Create distinct daylight and evening compositions, with selected Midas dining accessories. Deliver the whole-set view and useful details; do not omit chairs to simplify the shot.

On this page: Lifestyle (or a views-by-light series) first; once A7 has the accepted result, continue it with Variations and name the Midas accessories by SKU.

02

A five-seat modular corner

New Project → One by one → Living Rooms → New Composition + Website

Several source images describe three modules forming five seats. Keep their arrangement and upholstery, style the room with coordinated Midas tables and accessories, and request wide and close-up views.

On this page: Choose both outcomes and list “3 module” with the five seats in the notes.

03

Two chairs, excluding the table

Single item → Hero → Dining Chairs → Lifestyle

The source may contain a table or selection marks. Explicitly include only the two chairs. Place them in a relevant setting, with their form visible, plus a detail view.

On this page: Pieces “2 dining chair”, exclude “table”, view Wide view + close-up.

04

An accessory as the starting point

Single item → Hero → Relevant accessory category → Create with this item

A bowl, jewellery box or bookend becomes the main subject. Select suitable Midas furniture around it. A box may need open and closed views; a bookend should be shown performing its actual function.

On this page: Hero role with Create with this item; describe the open and closed views in Custom prompting.

05

An accessory supporting a room

Single item → Secondary → Accessories → New Composition

Place the same item on an appropriate supporting surface in a furniture-led composition. Keep it at credible scale, physically supported, and coordinated with the palette.

On this page: Secondary role with New Composition.

06

Towels, bedding and textiles

New Project → One by one → Relevant textile category → Website

Read swatches, pattern repeats, alternate views and supplier data as references. Show the product in use and close up. A colour swatch is not another physical item, and exact fibre content needs product data.

On this page: Website, with the supplier sheet as a specification file.

07

Restyle an existing room

Edit → New item + room reference → Lifestyle

Supply the room, the new product and a placement instruction. Retain room features requested by the user, replace only the selected pieces, and keep a consistent view for comparison.

On this page: Room and product references, with the placement in Custom prompting.

08

A mixed vendor batch

New Project → Batch → Product or collection

Each item or set has its own references, category and package. A towel, a lamp and a dining set remain separate jobs within the batch. Multiple angles of one product stay together.

On this page: Add one item per product; each is saved and sent as its own job.

09

Continue an accepted look

Edit → Choose from saving → Previous generation → Variations

Reuse the accepted space and original product references. Vary only the chosen dimensions, such as lighting or camera view.

On this page: Choose the sent version, retain its space or look, and pick what the variations change.
