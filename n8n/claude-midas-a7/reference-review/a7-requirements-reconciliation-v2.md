## What the references require for projects and collections

The [Projects/Manual guide](https://midas-client-studio.arafat312096.chatgpt.site/client-first-page/guide) establishes four project starts: product/collection, existing room, new styled space and saved project. A batch contains separate item/set jobs with their own references and category packages. Several photographs of one product remain references for that product.

The required persistent hierarchy is:

1. **Project:** owner, purpose, saved direction and current revision.
2. **Product or collection case:** the exact item/set inventory and immutable references; a coherent furniture set can be one case.
3. **Jobs:** versioned requests and changes within that case. A mixed batch groups separate cases; it does not create a collage.
4. **Output plan:** selected white, lifestyle, wide, detail and variation deliverables, with declared dependencies.
5. **Candidates and reviews:** exact source, contract, plan and output identity; revisions preserve history and invalidate affected approvals.
6. **Package:** all requested members, file facts, remaining holds, approved uses and actual cost evidence.

These are behavior requirements, not a mandate to copy the older Site's database or runtime. A7 already persists runs/events and the portal's private photos; it does not yet provide this complete durable project/case hierarchy. Chat history or an owner-generated job UUID is not a substitute for it.

## Important differences to preserve or resolve

- **Profiles:** all 43 reference profile identifiers are present in the saved A7 v2 profile data; A7 adds `plant-large`. This proves identifier coverage, not semantic or visual parity for every SKU.
- **White cleanup:** the manuals allow reusing an adequate original. A7's mandatory white-master path is a remaining routing issue, not a reason to add more generation stages.
- **Review percentages:** the older manual describes five-check scores with assessed coverage; A7's model scores are labelled judgments. Do not relabel them as calibrated measurements. Preserve unknowns and explicit count/identity failures.
- **Props:** older examples permit contextual books/plants. Later A7 decisions restrict additions to confirmed Midas pieces and room shell. This intentional difference must not be reversed by copying sample prompts.
- **Views:** older samples include inferred sides/cropped completions. A7's safer source-evidence holds must not be weakened just to reproduce those images.
- **Output sizes:** older files include other ratios and native sizes. Current guide targets square 2000/2048 generation; A7's 1125 derivatives are channel exports. Record native and delivered dimensions separately; confirm the requested pack rather than treating every historical size as a current default.
- **Owner approval:** existing manual authority remains. A failed/uncertain review must stay visible, and approved exceptions must not silently become reviewed catalogue releases.
- **Source-specific corrections:** the twelve-chair instruction, selected-chair table exclusion and proposed five-seat arrangement belong to their exact sources. Never apply them to unrelated uploads.
